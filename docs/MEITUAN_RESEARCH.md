# 美团/大众点评售货机数据采集研究

## 问题背景

用户发现：
1. 美团App搜索"自助售货机"会显示部分品牌
2. 需要获取售货机的**销量**和**用户评价**数据

## 数据来源分析

### 1. 美团平台

**数据特点**：
- 美团是本地生活服务平台，非专门的售货机平台
- 少数售���机品牌会入驻美团（如友宝部分设备）
- 主要是自动售货内容，而非设备本身

**可获取数据**：
- 商家名称、位置
- 用户评价
- 销量（可能不显示或显示不准确）

### 2. 大众点评

**数据特点**：
- 与美团同属一家公司
- 侧重于商户信息和用户评价
- 部分自动售货机会有商户页面

### 3. 支付宝小程序

**友宝小程序**：
- 友宝在支付宝有官方小程序
- 可以查找附近设备
- 但需要登录且API难以获取

## 获取销量和评价的挑战

| 数据类型 | 获取难度 | 原因 |
|---------|----------|------|
| **位置信息** | 中 | 部分平台有API或可以爬取 |
| **用户评价** | 高 | 需要逆向App API，且有反爬措施 |
| **销量数据** | 极高 | 属于商业机���，一般不公开 |
| **实时库存** | 极高 | 需要连接每台设备的API |

## 技术方案

### 方案A：美团/大众点评爬虫（中等难度）

**原理**：
1. 使用Playwright模拟浏览器
2. 搜索"自助售货机"、"友宝"等关键词
3. 解析商家页面获取评价数据

**限制**：
- 需要登录账号
- 有反爬机制（IP限制、设备指纹）
- 数据量有限

**示例代码框架**：
```python
from playwright.async_api import async_playwright

async def scrape_meituan():
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=False)
        page = await browser.new_page()
        
        # 访问美团
        await page.goto("https://www.meituan.com")
        
        # 搜索"自助售货机"
        await page.fill("input[placeholder*='搜索']", "自助售货机")
        await page.press("input[placeholder*='搜索']", "Enter")
        
        # 等待结果并解析
        await page.wait_for_selector(".poi-item")
        # ...解析逻辑
```

### 方案B：抓包分析（高难度）

**原理**：
1. 使用Charles/Fiddler抓包工具
2. 打开美团App，搜索售货机
3. 分析API请求和响应
4. 模拟API请求

**工具**：
- Charles Proxy（抓包）
- Frida（Hook分析）
- mitmproxy（中间人攻击）

**风险**：
- 可能违反服务条款
- 接口可能随时变化
- 需要处理加密和签名

### 方案C：支付宝小程序友宝（推荐）

**优势**：
- 友宝官方数据源
- 可以查找附近设备
- 数据相对准确

**获取方式**：
1. 支付宝搜索"友宝"
2. 进入友宝小程序
3. 查看附近设备
4. 抓包分析API

## 销量和评价数据的现实

### 销量数据

**现实情况**：
- 售货机销量属于运营商核心商业机密
- 一般不会在任何公开平台显示
- 即使显示也只是"月售XXX单"这种模糊数据

**替代指标**：
- 用户评价数量 → 可以推测受欢迎程度
- 设备位置（人流量） → 推测销量
- 补货频率（需要实地观察）

### 用户评价数据

**可获取性**：
- 大众点评/美团上可能有部分评价
- 但售货机作为自助设备，评价本身就很少
- 大多数用户不会给售货机写评价
