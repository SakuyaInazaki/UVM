# 数据要素对无人售货机选址��响研究方案

## 一、研究背景与目标

### 研究目标
探究**数据要素**对无人售货机**选址决策**的影响，识别关键数据要素及其作用机制，为优化选址提供数据驱动的决策支持。

### 核心问题
1. 哪些数据要素对售货机选址有显著影响？
2. 各数据要素的影响权重如何量化？
3. 如何利用数据要素构建科学的选址评价模型？

### 2.2 核心分析方法（基于学术文献）

| 方法 | 用途 | 工具 |
|------|------|------|
| **最近邻分析 (Nearest Neighbor)** | 判断分布模式（聚集/随机/均匀） | Python实现 |
| **标准差椭圆 (SDE)** | 分析分布方向和离散程度 | Python实现 |
| **缓冲区分析** | 分析周边设施对选址的影响 | Python实现 |

| **地理加权回归 (GWR)** | 探索影响因素的空间异质性 | PySAL |
| **空间多准则决策 (SMCDA)** | 综合多要素进行选址评价 | GIS + AHP |

## 四、实际数据分析结果

### 4.1 数据概况

基于实际采集的280条北京售货机POI数据：

| 指标 | 数值 |
|------|------|
| 总记录数 | 280台 |
| 空间范围 | 138.4km × 103.1km |
| 分布中心 | (116.4512°E, 39.9649°N) |

### 4.2 空间分布特征

#### 4.2.1 最近邻分析

| 指标 | 数值 | 解释 |
|------|------|------|
| 平均最近邻距离 | 1,521米 | 售货机之间的平均距离 |
| R比值 | 0.426 | R < 0.8 表示**聚集分布** |

**结论：** 北京售货机呈现明显的空间聚集模式，非随机分布。

#### 4.2.2 标准差椭圆分析

| 指标 | 数值 |
|------|------|
| 主轴标准差 | 24.8 km |
| 次轴标准差 | 20.8 km |
| 方向角度 | 32.8°（东北-西南走向） |

**结论：** 分布呈现东北-西南向的 elongated 模式，与北京城市空间结构一致。

#### 4.2.3 区域分布

| 区域 | 数量 | 占比 |
|------|------|------|
| 朝阳区 | 46台 | 16.4% |
| 通州区 | 30台 | 10.7% |
| 大兴区 | 27台 | 9.6% |
| 房山区 | 26台 | 9.3% |
| 顺义区 | 24台 | 8.6% |

#### 4.2.4 缓冲区分析（500米半径）

- 平均每台售货机500米范围内：**0.6台**其他售货机
- 最密集区域（石景山万达广场）：**4台**聚集

## 五、数据要素影响分析

### 5.1 已识别的影响因素

基于实际数据观察，以下因素对选址有显著影响：

#### 5.1.1 商业综合体聚集效应
- **观察：** 石景山万达广场周边500米内有4-5台售货机
- **数据要素：** 商场POI、商业设施密度
- **影响机制：** 商场带来稳定人流量

#### 5.1.2 类别与选址关联
| 售货机类型 | 数量 | 典型选址 |
|-----------|------|---------|
| 成人用品 | 154台 (55%) | 商场、娱乐场所 |
| 潮玩/泡泡玛特 | - | 商场、购物中心 |
| 综合售货机 | - | 写字楼、交通枢纽 |

#### 5.1.3 空间自相关
- R比值0.426 < 0.8，表明存在显著的空间正相关
- **选址策略：** 新点位应优先考虑现有售货机周边区域

### 5.2 待深入分析的要素

| 数据要素 | 获取方式 | 预期影响 |
|---------|---------|---------|
| 地铁站距离 | 高德/百度API | 正相关 |
| 写字楼密度 | 高德/百度API | 正相关 |
| 人流量 | 实地调研/移动信令 | 正相关 |
| 竞品密度 | 便利店API | 负相关 |

## 六、分析步骤与实现

### 阶段一：描述性空间分析 ✅（已完成）

**目标：** 了解现有售货机的空间分布特征

#### 1.1 最近邻分析 ✅
- **方法：** Nearest Neighbor Analysis
- **输出：** R比值 = 0.426，聚集分布
- **代码：** `src/location_analysis/main_simple.py`

#### 1.2 标准差椭圆分析 ✅
- **方法：** Standard Deviational Ellipse
- **输出：** 主轴24.8km，方向32.8°

#### 1.3 缓冲区分析 ✅
- **方法：** 500m缓冲区统计
- **输出：** 平均0.6台邻居

### 阶段二：相关性分析（待补充数据）

**目标：** 量化各数据要素与选址的关系

#### 2.1 缓冲区相关性分析
- **方法：** 统计各距离范围内设施数量与售货机存在的关系
- **需要数据：** 地铁站、商场、写字楼POI

#### 2.2 地理加权回归
- **模型：** Y = β₀ + ΣβᵢXᵢ + ε
- **因变量：** 售货机密度
- **自变量：** 各类设施密度

### 阶段三：选址评价模型（待开发）

**目标：** 构建综合选址评分模型

#### 3.1 指标体系构建
```
目标层：选址适宜性
├── 需求潜力（权重25%）
├── 交通便利性（权重20%）
├── 商业环境（权重20%）
├── 竞争环境（权重20%）
└── 场地特征（权重15%）
```

#### 3.2 综合评价
```
选址得分 = Σ(指标标准化值 × 权重)
```
